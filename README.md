# 个人主页

第一阶段：Vue + Vite 工程初始化。Three.js 已作为依赖安装，地球将在后续阶段实现。

## 本地开发

在项目目录打开终端：

```sh
npm install
npm run dev
```

打开终端显示的本地地址。页面计数按钮用于验证 Vue 响应式交互。

## 构建与预览

```sh
npm run build
npm run preview
```

`dist/` 是构建产物，不提交到 Git。`package-lock.json` 应提交，保证依赖版本可重复安装。

## 文件入口

- index.html：网页入口和挂载节点。
- src/main.js：创建 Vue 应用。
- src/App.vue：首页组件与计数交互。
- src/style.css：页面样式。
- vite.config.js：开发构建配置。

尚未实现三维地球，也尚未部署。

## 第二阶段：电脑端布局

- App.vue 组合页头、地球区域、个人资料和页脚。
- src/components/EarthScene.vue 预留 Three.js 容器，目前没有地球或拖拽功能。
- src/components/ProfilePanel.vue 包含个人信息和可切换的关于我、我的作品面板。修改 profile 对象可替换姓名和介绍。
- src/style.css 使用 CSS Grid 构建左右两栏，仅考虑电脑端，最小布局宽度为 1000px。
- 已通过生产构建，并在浏览器 1440 × 900 视口检查布局和页签切换。

开发服务器已运行时直接访问 http://127.0.0.1:5173/，不需要再次运行 npm run dev。

## 第三阶段：真实地表三维球体

- 使用 NASA Blue Marble 2004 年 7 月地表合成影像，5400 × 2700，约 1.62 MB；来源记录在 public/textures/SOURCES.md。
- src/earth/createEarth.js 创建场景、相机、球体、光照和渲染器，使用 sRGB 纹理。
- EarthScene.vue 在 onMounted 中初始化，onBeforeUnmount 中释放纹理、材质、几何体、观察器和渲染器。
- ResizeObserver 根据容器尺寸调整相机比例和距离，避免地球拉伸或裁切。
- 支持加载、超时、失败与重新加载提示，按需渲染静止画面。
- 当前没有拖拽、缩放、夜景、独立云层与大气效果；第四阶段接入交互。
- 已在 1440 × 900 浏览器视口确认纹理显示。下载完成后重新构建以包含本地纹理。

## 第四阶段：地球交互

接入 OrbitControls：左键拖拽让相机围绕地球旋转，滚轮缩放，禁止平移，带阻尼与远近限制。恢复视角回到初始亚洲视角。窗口改变时保留观察方向和相对缩放比例。标签页隐藏时暂停控制器循环，卸载时清理控制器与监听器。
已验证拖拽、缩放和恢复视角。地球本体及光源方向保持固定；夜景和云层尚未接入。

## 第五阶段：固定昼夜与城市灯光

- 新增 src/earth/dayNightMaterial.js，使用世界空间表面法线与固定太阳方向的点积决定昼夜。
- smoothstep 平滑晨昏过渡，城市灯光仅在背光侧显现；太阳不随时间或相机变化。
- 新增 NASA Black Marble 2016 夜光图（3600 × 1800），与白天图使用相同 UV。
- 两张纹理完成后才显示地球，任一失败或超时均可重试。卸载时释放两张纹理。
- 在 1440 × 900 视口检查初始晨昏线及拖拽至夜侧的效果，生产构建通过。
- 夜光与白天地表不是同一年份的数据；仅用于视觉展示。当前仍无云层、大气光晕与海面反光。

## 第六阶段：云层、大气与海面反光

- earthLayers.js：半径 1.008 的透明云层、半径 1.035 的大气球壳。均使用固定太阳方向；光晕为视觉近似，不是完整物理散射。
- earth-details.jpg 来自 Three.js 官方示例，原作者 Solar System Scope，CC BY 4.0。署名及许可见 public/textures/SOURCES.md。
- 云层蓝通道控制透明度，缓慢移动 UV；海陆粗糙度绿色通道限定海面高光，并以云密度抑制云下反光。
- 云层非实时气象，未实现云影。用户启用减少动态效果时停止云层移动；隐藏标签页暂停循环。
- 已通过构建及电脑端浏览器显示、拖拽、缩放检查。所有纹理本地加载。
